This repository is the DummyAgent created with LangChain4
Here the focus in Langchain fundamentals and the concepts that are core to engineering harness around the LLM Model.
The use case or customer scenario can be later targeted or implemented and thus a project can be made after that.
Later on focus for public viewership can be targeted to connect/impress/share learning with others/recruiters/developers/friends.


Part 1 : 
This project is made to run on local ollama setup as due to spending constraints. The model here picked is qwen3.5:2b model as it supports tool calling + multi-modal. This model can run on a 4GB Graphics and 16GB ram.
